# Contributing to Awesome Letta

Thanks for helping grow the list. This repository links to community work; it does not host code.

## How to contribute

1. Fork this repository and create a branch.
2. Add your resource to the most specific section of `README.md` that fits, after existing entries, using this format:

   `- [Name](https://example.com) - One sentence describing what it does.`

3. Open a pull request. One addition per PR, or a small batch of closely related additions.

## What belongs

- Projects built on Letta: apps, bots, integrations, agents
- Tools: CLIs, MCP servers, plugins, scripts
- Learning material: tutorials, guides, videos, blog posts
- Agent resources: templates, skills, mods

## The bar

- The link must work and the project must be usable today. If the install steps don't run, the entry won't be merged.
- Open source is strongly preferred for tools and projects.
- Entries link out to your repository, docs, or video. Do not commit source code, documentation folders, or editor junk (`.DS_Store`, stray `.gitignore` files) to this repository.
- Descriptions are one sentence and state what the thing does. No marketing language.
- If you add or rename a section, keep the table of contents at the top of the README in sync.

Maintainers may edit entries for style, move them between sections, and remove entries for projects that stop working or become unmaintained.
